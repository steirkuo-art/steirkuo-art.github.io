# DuoQuest 網站（GitHub Pages）

- index.html：首頁
- privacy.html：隱私權政策（App Store「隱私權政策網址」填這頁）
- support.html：支援頁（App Store「支援網址」填這頁）

- .nojekyll：讓 GitHub Pages 會放出 .well-known 資料夾。
- 頁尾目前只寫「© 2026」，之後補上護照英文名。
